Zugriff auf lokale Dateien erlauben

Die Seite ist eine lokale Datei (file://). Chrome erlaubt Erweiterungen dort nur Zugriff, wenn du es einmalig freigibst:

  1. Erweiterungsdetails öffnen (Button unten).
  2. „Zugriff auf Datei-URLs zulassen“ einschalten.
  3. Die HTML-Seite neu laden und das Extension-Icon erneut klicken.

Auf dieser Seite nicht möglich

Chrome erlaubt Erweiterungen auf manchen Seiten keinen Zugriff, z. B. auf chrome://-Seiten, dem Chrome Web Store oder der neuen Tab-Seite. Auf normalen Webseiten, localhost und lokalen Dateien funktioniert HTML Feedback.
